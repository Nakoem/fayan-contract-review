## 设计概念

一封薰衣草色的手写情书。日系治愈风，温暖、轻盈、安静，像图书馆午后阳光下写下的那封信。

## 设计方案

| 维度 | 选择 |
|------|------|
| 风格 | 日系治愈风 |
| 配色 | 薰衣草牛奶：淡紫(#e8dff5) → 粉白(#f0d4e0) → 暖白(#fff5f0) 垂直渐变 |
| 背景 | 散落装饰：半透明emoji（🌸✉️💜🪻✨）随机分布在背景上 |
| 动画 | 情书纸片：折纸爱心飘起 + 纸飞机飞过 + 水彩便签晕染 |
| 字体 | 标题 Lora Italic + 正文 Noto Serif SC |
| 布局 | 三等分对称：上方标题 → 中间爱心 → 下方文字，三行诗节奏 |
| 爱心 | 薰衣草紫→粉渐变 SVG 贝塞尔爱心，带呼吸脉动动画 |

## 技术方案

- 纯 HTML + CSS + JS，零依赖
- 字体：Google Fonts（Lora + Noto Serif SC）
- 动画：CSS @keyframes + JS requestAnimationFrame + setInterval
- Canvas 用于水彩晕染效果
- SVG 用于中心爱心

## 动画清单

1. **SVG爱心呼吸** — CSS @keyframes scale 1.0→1.12，~1.2s周期
2. **折纸爱心飘起** — JS动态生成，菱形div旋转45°，从底部飘升+摇摆
3. **纸飞机划过** — emoji ✈️/📨 从左上→右下斜飞，带旋转
4. **水彩便签晕染** — Canvas 半透明色块随机浮现+消散
5. **背景emoji淡入淡出** — CSS opacity动画，极慢周期

## 性能目标

- 稳定 30fps+（移动端 60fps 目标）
- 粒子总数 ≤ 30 个同时存在
- Canvas 尺寸自适应 resize

## 验收标准

1. 浏览器打开即见完整动画，无需任何操作
2. 所有文字清晰可读，字体加载正常
3. 爱心脉动流畅，无卡顿
4. 纸飞机和折纸爱心动画自然
5. 移动端布局不自崩
