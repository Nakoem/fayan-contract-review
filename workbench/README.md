# 合同工作台（个人版）· V1.0

> 法眼企业版的 C 端产品线：同一套审查内核，另一种包装。
> 给没有法务部的人，一个「一个人的法务部」。

---

## 快速开始

1. 双击 `dist/index.html`（Chrome / Edge，1280px 以上）
2. 右上角「设置」→ 选服务商 → 填 API Key → 保存
3. 粘贴合同，或上传 PDF / Word / 合同照片（扫描件可点「识别文字」走 OCR），或点一份示例合同 → 选合同类型与审查视角 → 「开始审查」
4. 手上还没有合同？到「合同范本」选一份范本，填关键信息生成初稿，再一键送去审查
5. 审完可点「加入台账」，在「合同台账」里记到期日、续签日与多期付款节点；案头会显示 30 天内待办
6. 合同改了新版？到「版本对比」把旧版和新版放一起，看条款差异与风险变化，导出对比报告
7. 要发函？到「文书」起草催款函、解除通知、整改函、律师函草稿或通知类文书；到「法条」离线查法规、判例、地方政策与税务口径
8. 合同原件、补充协议、往来记录可以挂在台账条目下；设置里可导出 / 导入 JSON 备份（不含 API Key 与附件文件）

首次使用必须配置自己的模型 Key。合同原文只会发送给你选择的模型服务商；其余数据留在本机浏览器。

### 服务商

| 服务商 | 默认模型 | 浏览器直连 |
|---|---|---|
| DashScope（通义） | `qwen3.8-max-0902` | ✅ |
| DeepSeek | `deepseek-flash` | ✅ |

模型名可编辑；Key 分服务商保存在 IndexedDB。

### 文件解析

- 支持文字层 PDF、DOCX、TXT / MD、JPG / PNG / WEBP；旧版 `.doc` 会提示另存为 `.docx`
- 文件只在本机浏览器解析，不上传；点「开始审查」时才把提取出的文字发给所选模型
- 扫描版 PDF（没有文字层）和图片会提示「识别文字」：PDF 在本机渲染成页图，再由用户明确点击后逐页发给所选多模态模型；最多 30 页，单页宽 1600px，识别完填回输入框，发送前可核对
- OCR 只在用户点击时上传页图；隐私提示会明确写出「OCR 图片会发给所选服务商」
- 上限：单文件 25MB、PDF 300 页、提取文字 20 万字；送审仍受 5 万字限制
- 解析器版本与许可证见 `vendor/README.md`

### OCR（扫描件 / 照片）

- 入口复用现有上传框，没有单独页面：上传没有文字层的 PDF 或 JPG / PNG / WEBP 后，出现「识别文字 / 取消」
- PDF 由 PDF.js 在本机逐页渲染成 JPEG（最大宽 1600px，质量 0.82），再一页一个请求发给当前服务商的多模态模型；图片直接压缩后发送
- 必须由用户点击「识别文字」才会上传；最多 30 页；识别结果填回合同输入框并提示「请核对」
- 当前 DashScope 预设支持 `deepseek-v4.1-flash` 等多模态模型；DeepSeek 官方接口对应 `deepseek-flash`；Key 与服务商不匹配会返回 401 并提示
- OCR 请求关闭 thinking（`enable_thinking:false`），单页约 400 tokens；识别失败可取消，不会自动重试

### 法条速查

- 侧栏「法条」页，离线检索 70 条法规 / 判例 / 地方政策 / 税务口径 / 新规动态，不联网、不调用模型
- 中文按「单字 + 双字」切词，本地 BM25 打分；长查询至少命中两个双字词或整串原样出现，避免常用单字把整库捞出来
- 分类：法规 / 判例 / 地方 / 税务 / 新规；搜索结果默认展开第一条，命中词高亮，正文可展开
- 数据来自构建时内联的 `knowledge/*.json`，与审查链路的本地法条匹配共用同一份知识资产

### 备份与恢复

- 设置抽屉「备份与恢复」：导出 JSON 包含设置、审查历史、台账、规则和当前审查结果；不包含 API Key，也不包含附件文件
- 导入会覆盖本机审查历史 / 台账 / 规则，设置恢复但 API Key 保留；备份里的台账不含附件，导入后会清理没有对应台账的附件
- 单文件上限 500 条审查 / 台账记录；导入文件上限 50MB

### 合同台账

- 审查结果页「加入台账」自动带入合同名称、类型、对方、金额、起止日期与首期付款节点；也可在台账页手动新增
- 字段：名称 / 类型 / 状态 / 对方 / 金额 / 起止日期 / 续签日 / 多期付款节点（日期 + 金额 + 备注）/ 备注
- 案头「待办 · 30 天内」汇总到期、续签与付款节点，逾期会标红；「我的合同」按风险色条列出全部台账条目
- 台账页按状态胶囊、类型下拉、关键词筛选；关键词与案头 / 侧栏搜索共用，类型与状态筛选独立叠加；表格显示合同名 / 对方 / 金额 / 到期日 / 状态，点行直接编辑
- 右侧「关键日期」按时间轴列出到期、续签与所有付款节点；导出 CSV 含续签日期与付款节点列，按条或全部导出 `.ics` 到手机日历
- 「对方档案」按对方主体汇总：签过哪些合同、合同金额合计、最近到期、历史高风险条款口径，可从台账对方列或表头按钮打开
- 台账条目可挂附件：合同原件、补充协议、往来记录等，存在独立 IndexedDB 文件库；单份 ≤ 25MB、每份合同合计 ≤ 100MB，可下载 / 删除，删合同会一起清理附件
- 全部存在本机 IndexedDB；CSV 公式注入已做文本化处理

### 合同版本对比

- 侧栏「版本对比」：旧版 / 新版左右并排，可手动粘贴、上传 PDF / DOCX，或从当前审查 / 历史审查带入
- 本地按条款标题对齐，剥离「第 X 条」编号以容忍整体重编号；条款内按中文标点分段做差异高亮；没有条款结构的文本按段落对齐
- 两边都从审查带入时，额外比较高 / 中 / 低风险数量、评分变化，以及新增 / 消除 / 等级变化的风险
- 条款文字改了、但规则和位置没变时，仍算同一条风险，不会误报成「新增 + 消除」
- 支持「只看变化」与导出 Word 对比报告；对比全程本地，不调用模型、不上传

## 关键设计

- **规则数据化**：规则存在 `RULES` 数组里，提示词由代码拼装；规则编辑器只读写这份数组，不改审查链路。
- **审查视角（V1.5）**：审查前按合同角色选择立场——租赁看出租人 / 承租人、劳动看用人单位 / 劳动者等，默认中立。视角进入评估与复核提示词：非中立时只报对该方不利的风险，对我方有利且不违反强制性规定的条款不报；可能无效或被调整的仍提示可执行性风险。报告元信息与结果统计会显示所选视角，选择随设置持久化，历史记录也会保留。
- **5 步流水线**：抽取（LLM）→ 法条（本地 BM25）→ 评估（LLM）→ 复核（本地 + 轻量 LLM）→ 报告（本地模板）。
- **报告不交给 LLM 排版**：LLM 只吐结构化 JSON，六段式报告由本地模板渲染，格式稳定。
- **Word 导出（真 `.docx`）**：不再把 HTML 改扩展名，`docx.js` 现场打一个 Office Open XML 包（`[Content_Types].xml` + `word/document.xml` + altChunk），Word 打开无「文件格式与扩展名不匹配」警告。正文仍是 A4 页面 + 表格重排：统计卡横排、风险条目固定标签列、低风险条款表格化，去掉复制按钮和折叠块，法条参考改为浅灰块保留；缺失条款显示为「缺失条款 / 本合同未约定该条款」，同一条款内未单独成条的其他约定（如提前解约违约金）显示为「其他约定」。
- **V2 文书起草（2026-11-26）**：侧栏「文书」页支持六类——催款函、解除 / 终止通知、整改函、律师函（草稿）、续签提醒函、变更通知函。可从当前审查、历史记录或台账选合同，自动带入发函方 / 对方、金额、日期与审查条款；只把事实和勾选条款交给模型，不发送整份合同。提示词强制不编造事实、缺失信息写【待补充】、落款用起草日期，输出纯文本可逐字修改；支持复制和导出真 `.docx`，草稿默认勾选高风险条款，律师复核提示随文输出。律师函另加强制规则：标题写「律师函（草稿）」、第二行写「本稿需执业律师复核后方可发出」、律所 / 律师 / 执业证号只能写【待补充】，不得编造。
- **V2 合同范本（2026-11-26）**：侧栏新增「合同范本」，6 类合同全部开放。选范本后填主体、金额、期限等关键信息，本地替换生成可编辑正文，不调用模型、不上传；未填字段保留【待填写】，支持复制、导出真 `.docx` 和「送去审查」（同步合同类型，不自动发起审查）。条款按常见合同结构手写，不是官方示范文本，正式使用前请律师复核。
- **V3 合同版本对比（2026-11-26）**：侧栏新增「版本对比」，旧版 / 新版来源支持手动、当前审查、历史审查。本地按条款标题做 LCS 对齐，剥离「第 X 条」编号以容忍重编号；未匹配条款按 bigram 相似度回退配对，条款内按中文标点分段做差异高亮。两边都带审查结果时，按规则 + 条款文本匹配风险；条款文字改了但同规则同位置仍视为同一条风险，输出新增 / 消除 / 等级变化与评分变化，统计优先使用报告 counts（低风险不漏算）。导出 Word 时把 `<del>/<ins>` 换成普通 span，避免 Word 吞掉旧版差异。全程本地，不调用模型。
- **V3.1 个人版补全（2026-11-26）**：在 V3 之后补齐 PRD 剩余项——OCR 扫描件 / 照片（复用上传入口）、JSON 本机备份与恢复、台账多付款节点 + 续签日、对方主体档案、律师函草稿 + 通知类文书、附件管理、离线法条速查。新增 `ocr.js` / `backup.js` / `attachments.js` / `law.js`，全部本地优先；附件独立 IndexedDB 文件库，不随 JSON 备份导出；法条速查使用构建时内联的知识库，零网络请求。
- **台账多节点与续签**：`payments[]` 取代单个下次付款字段，旧 `paymentDate/paymentAmount` 继续兼容读取；提醒、关键日期、CSV、ICS 都按节点展开，每期付款有独立 UID；续签日进入案头 30 天提醒与日历导出。
- **对方档案**：不新建重复数据表，直接按台账 `counterparty` 聚合合同、金额、最近到期与关联审查的规则级风险次数；空主体不参与聚合。
- **附件管理**：二进制存独立 IndexedDB（`contract-workbench-files`），元数据与 Blob 分 store，列表不加载文件本体；删除台账时清理附件，导入备份时按新台账 prune 孤儿附件；浏览器无 IndexedDB 时明确报错，不回退 localStorage。
- **法条速查**：本地 BM25（单字 + 双字切词），查询侧只取双字并要求长查询至少命中两个词或整串，减少中文单字噪声；结果按类别过滤，命中词在正文里安全高亮。
- **评级确定性**：任一维度 ≥4 → 高；任一 =3 → 中；均 ≤2 → 低。
- **综合评分**：`min(100, 高×15 + 中×6 + 低×1)`。
- **脱敏**：身份证 / 手机号 / 银行卡 / 邮箱正则 + 用户自填名称列表；默认开启。
- **单文件交付**：零外链、零 CDN、零外部字体；`file://` 下 IndexedDB / 剪贴板 / PDF / DOCX 解析实测可用。
- **解析器内联**：PDF.js 与 Mammoth 以 base64 / 源码形式打进单文件，运行时零网络请求；当前交付物体积约 3.3MB。
- **单槽恢复 + 最近审查**：当前结果存 IndexedDB，刷新不丢；每次审查另存一条历史，案头支持搜索、打开、删除、清空。
- **历史预览脱敏**：首页摘要中的证件 / 手机 / 银行卡 / 邮箱固定显示占位符，完整原文只留本机。
- **台账与提醒**：审查结果可一键入台账；到期 / 付款节点在本机计算，案头汇总 30 天内待办，支持 `.ics` 日历与 CSV 导出。
- **台账自动带入（2026-11-25）**：点「加入台账」时从合同原文本地识别对方主体、合同金额、起止日期、下次付款日 / 付款金额与备注，按审查视角取对方（承租人视角带出租人，中立显示双方）；支持角色前置（出租人（甲方））、供方 / 需方、甲方 / 乙方、大写金额、万元 / ￥ 等常见写法；不额外调模型、不上传，识别不到的字段留空，保存前都能改。
- **高风险定位**：点风险清单里的高风险条目，原文对应条款出现旋转光束描边（参考问数精灵登录按钮的 BorderBeam，沿用 ocean 蓝紫配色；长条款上转速放缓到 3.1s）；中/低风险仍用闪烁定位。
- **设计稿外壳**：按 ardot P1 复刻 236px 侧栏、Brand Mark 图标、案头三卡与「最近审查 / 我的合同」双入口；整体沿用原天空玻璃配色。侧栏搜索是全局搜索，同时查审查记录与台账条目，台账结果可直接打开编辑；侧栏、最近审查、我的合同、台账页四个搜索框共用关键词并实时同步。合同台账按 P3 改成表格 + 关键日期时间轴；审查台 / 条款库的版式、配色与按钮保持原样。
- **审查规则可编辑（V1.5）**：侧栏新增「审查规则」页。111 条内置规则可修改、可停用，但不能删除；自定义规则可新增 / 编辑 / 删除。关键词、判定条件、风险等级、法条依据、建议话术都能改，改完立即参与下一次审查；规则状态存本机 IndexedDB，刷新不丢。写入带版本校验，多标签页不会互相静默覆盖；审查中途改规则也只影响下一次审查。条款库同步显示「已停用 / 自定义」标记。
- **法条依据核对（2026-11-24）**：111 条内置规则的法条依据按中国政府网、最高人民法院、人力资源和社会保障部等官方渠道现行文本逐条复核，修正 6 处条文号：房屋租赁专属管辖改为民事诉讼法第 34 条、协议管辖改为第 35 条、放弃社保改为劳动争议司法解释（二）第 19 条、委托作品著作权改为著作权法第 19 条、预付式「概不退款」改为预付式消费司法解释第 9 条、停业逃退款改为第 7 条与第 23 条。规则页展示核对日期与 20 部法规 / 司法解释版本；规则是离线预筛，法规修订后需重新核对。
- **P0 + P1 扩容（2026-11-24）**：新增 45 条规则，覆盖消保法及实施条例、公司法、合伙企业法、专利法、商标法、反不正当竞争法、仲裁法（2025 修订）等此前空白；6 类合同规则数变为租赁 18、劳动 20、买卖 15、服务 17、合作 16、借款 14，通用 11。

## 已知限制（V1.0）

- OCR 依赖所选模型的多模态能力：当前 DashScope `deepseek-v4.1-flash` / DeepSeek `deepseek-flash` 可用；最多 30 页，手写体、印章遮挡、低清照片识别可能出错，识别后必须人工核对
- 文书支持六类，但仍不做批量发送、电子签和草稿持久化；律师函只是草稿，必须由执业律师复核并由律所正式出具；多案件 / 完整企业台账仍不做
- V2 范本 6 类已开放，但都是通用条款初稿，不替代律师按实际交易修改；刷新后不保留填写内容
- V3 版本对比是本地文本对齐，不是法律意义上的版本核对；条款大规模重写或结构完全不同时，可能退化为按段落配对；两边都需从审查带入结果才能比较风险变化；单版上限 5 万字
- Word 对比报告在分页处可能拆分较长条款行，内容不会丢失；需要严格分页时可在 Word 里手动调整
- 台账支持多期付款与续签，但不做循环提醒 / 自动续签 / 多人同步；对方档案按对方名称精确聚合，同一公司不同写法不会自动合并
- 附件单份 ≤ 25MB、每份合同合计 ≤ 100MB；附件不进入 JSON 备份，换电脑需另行拷贝浏览器数据；导入备份会清理没有对应台账的附件
- 法条速查是离线法规库（70 条，核对至 2026-11-24），不是完整法规数据库；法规修订后需重新核对，检索结果不构成法律意见
- 台账从审查结果加入时会本地识别对方 / 金额 / 日期 / 付款节点，但复杂 / 非标准合同可能漏填，保存前需核对
- 历史只做单机「最近审查」，不是完整合同台账
- 浏览器直连仅支持 DashScope / DeepSeek；Ollama 预设不在 V1.0
- 单次输入上限 5 万字（3 万字起提示）
- 报告右下角有 CSS「已审查」印章；打印页眉 / 页码由浏览器打印设置控制，应用不注入页码
- 单文件构建产物上限 4MB；当前约 3.3MB
- AI 输出仅供参考，不构成法律意见；正式签署前请由执业律师复核
