项目经历

法眼 · AI 合同审查 Agent（4个月，独立开发）

  GitHub: github.com/pppppgy/fayan-contract-review
  一个从零到产品级的 AI 合同审查系统，覆盖 6 种合同类型，
  内置法规/判例/地方政策/税务四重知识库。

  1. ReAct Agent 架构设计与实现
     - 设计 10 工具 ReAct 自主决策循环，Agent 自动完成
       "提取条款 → 查法规 → 逐条分析 → 完整性检查 → 生成报告"全流程
     - 支持 6 种合同类型（房屋租赁/劳动/买卖/服务/合作/借款），
       每种配备法条级法定红线标准

  2. RAG 检索增强生成全链路
     - 66 条法规/判例/政策/税务知识迁移到 Chroma 向量数据库（216 chunks）
     - DashScope Text-Embedding 实现语义检索，
       解决关键词"押金不退"无法命中"押金退还"的问题
     - 混合检索策略（向量语义检索 + 关键词精确匹配兜底）

  3. MCP 协议标准化
     - 5 个法律搜索工具封装为 MCP Server
     - Claude Code、Cursor 等 AI 可直接调用法眼的法规/判例搜索能力

  4. FastAPI + Docker 容器化部署
     - Streamlit 单体 → FastAPI REST 服务（同步/异步审查、Swagger 文档）
     - Dockerfile（多阶段构建）+ docker-compose.yml，一键部署

  5. 工程化基础建设
     - 日志系统：loguru CLI/Web 双模式，文件轮转（10MB）
     - Prompt 版本管理：15 个提示词 YAML 外部化 + 惰性代理
     - 自动化评估：三维度（格式合规 + 风险召回率 + LLM-as-Judge），47 个测试点

  6. 模型选型与评测

     对 4 个模型进行完整的 Function Calling + 报告质量对比测试：

     模型           JSON合规  格式规范  法律判断  速度   结论
     qwen-plus      偶有错误   遵守模板   判断准确   快    最终选择
     qwen-max       稳定       合规       保守降级   快    法律判断不够锐利
     qwen3.6-plus   稳定       间或偏离   思考冗长   慢    速度不可接受
     deepseek-v3.2  稳定       顽固Markdown 判断准确 快    法务系统不兼容

     选型逻辑：围绕具体任务定义 4 维评测标准——JSON合规、格式遵守、
     法律判断、响应速度。最终选 qwen-plus 因为它最"听话"，缺陷可控。

  7. 疑难技术攻坚

     问题                      排查深度        最终方案
     qwen-plus JSON格式错误     8轮迭代         <<TOOL>>标签绕过DashScope校验
     DeepSeek顽固输出Markdown   3版提示词无效   切回qwen-plus
     合同类型5→13→6回退       扩展后JSON暴增   回退到6种，宁精勿多
     报告被模型"总结"覆盖      模型擅自总结     last_report无条件优先返回
     模型逐字输出内部铁律       铁律放模板底部   铁律移到System Prompt

  8. 系统设计决策

     - 为什么用 ReAct Agent 而不是固定流水线？
       固定流水线"一步出错全崩"，ReAct 让 AI 自主决定步骤，容错更强
     - 为什么先做工程化再做 RAG？
       没有评估体系就上 RAG，改完不知道好坏
     - 为什么选 Chroma 而不是 Milvus？
       数据量 23K 字符，够用就好；量大可平滑升级
     - 为什么 MCP 协议放最后？
       先把工具稳定、接口定型，再暴露为标准协议

  技术栈：
    Python | FastAPI | Streamlit | Docker | Chroma | MCP SDK
    阿里云百炼 DashScope (qwen-plus) | OpenAI 兼容 SDK | loguru | PyYAML


法眼 · 法律问答 Bot（1周，独立开发）

  基于法眼四重知识库的 AI 法律对话助手。
  Streamlit 聊天界面，流式对话 + 双模式切换。

  - 跨库 RAG 检索：同时检索法规/判例/政策/税务/资讯 5 个向量库
  - 流式输出：SSE 实时逐字显示，支持上下文连续
  - 双模式：不传合同→泛法律问答；上传合同→针对合同条款问答
  - 对话记忆：保留最近 20 轮对话上下文
  - 法条引用：每条回答注明法规出处（如《民法典》第 585 条）

  技术栈：Streamlit | SSE 流式 | RAG 跨库检索 | 多轮对话记忆
